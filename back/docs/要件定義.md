# 要件定義

## 技術スタック

今回は短期開発なため、学習コストの低い Go を使用しますが、
開発が安定次第 Rust に切り替える予定です。<br />
それに伴い DB も Go と互換性の高い PostgresSQL を使用しますが、開発が安定次第 MySQL に切り替える予定です。

- **開発言語**：Go
- **Web フレームワーク**：Gin
- **データベース**： PostgresSQL
- **API 形式**：REST API

## 全体像

- **Router**： ユーザからの「記事を追加・編集したい」といったリクエストを適切なハンドラに譲渡します。
- **Handler**： 実際の処理内容を書く場所です。
- **Database**： 記事の内容を保存する場所です。
- **Model**： プログラム内で扱う記事のデータ構造を定義します。

## 機能要件

### 1．データモデル

「記事」としてどのような情報を保存すべきかを以下のように定義します。

記事投稿（Articles/POST）モデルの場合

- **ID**： 一意の識別番号
- **Title**： タイトル
- **Content**： 内容
- **Author**： 投稿者・または組織名・役職名
- **CreateAt**： 作成日時
- **UpdateAt**： 更新日時

### 2．API エンドポイント

サーバがフロントエンドからどのようなリクエスを受け付けるかを以下の様に定義します。

| URL            | HTTP メソッド | 機能                         |
| -------------- | ------------- | ---------------------------- |
| `/articles`    | GET           | 全記事の一覧を取得           |
| `/articles/id` | GET           | 指定した ID の記事１権を取得 |
| `/articles`    | POST          | 新しい記事を DB に保存       |
| `/articles/id` | PUT           | 指定した ID の記事を更新     |
| `/articles/id` | DELETE        | 指定した ID の記事を削除     |
